Before launch

What this starter does and what the production backend still needs.

Does this version download from every platform?

No. It automatically detects common platform names and recognizes direct media-file URLs, but it does not bypass platform restrictions or download videos from social-platform pages. That requires permitted, platform-specific integrations and a backend.

Will it show 4K, 2K, 1080p, 720p, 480p and 360p?

The production version should list only qualities confirmed by the source. A link alone does not always reveal the available resolutions; a compatible metadata endpoint or authorized API is needed.

Can it handle private or protected videos?

It should not bypass login restrictions, DRM, paywalls, or other access controls. Use official download/export options for content you own or have permission to save.
